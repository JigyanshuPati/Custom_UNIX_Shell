A UNIX shell written from scratch in C++17. It implements a read-eval-print loop that tokenizes commands, parses pipelines, and executes them using the POSIX process API. External commands are launched with `fork()` and `execvp()`, while input/output redirection (`<`, `>`, `>>`) uses `open()` and `dup2()`, and pipelines of arbitrary length are connected using `pipe()`. Eight builtins (`cd`, `pwd`, `echo`, `help`, `jobs`, `fg`, `bg`, `exit`) run directly in the shell process to modify shell state when required. The shell also provides real job control by placing each pipeline in its own process group with `setpgid()`, transferring terminal control using `tcsetpgrp()`, and ignoring `SIGINT`, `SIGQUIT`, and `SIGTSTP` in the shell so signals are delivered to foreground jobs. Background jobs (`&`) are tracked in a job table, reaped without blocking, and can be suspended or resumed using `fg` and `bg`.
